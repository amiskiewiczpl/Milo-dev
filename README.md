# Usługi Księgowe MIŁO

Strona usługowa Miłosza Jury, przygotowana jako statyczny projekt HTML, CSS i JavaScript dla GitHub Pages.

## Uruchomienie lokalne

Otwórz `index.html` w przeglądarce. Do działania obecnego szkieletu nie są potrzebne zależności ani proces budowania.

## Struktura

- `index.html` — strona główna one-page
- `privacy.html` — robocza strona polityki prywatności
- `404.html` — strona błędu GitHub Pages
- `css/` — style
- `js/` — interakcje menu
- `assets/` — logo i zdjęcia

Prywatne notatki projektowe są przechowywane poza katalogiem repozytorium i nie są publikowane na GitHubie.

## Publikacja

W GitHub: `Settings` → `Pages` → `Deploy from a branch` → `main` → `/ (root)`.
